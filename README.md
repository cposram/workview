# 📝 遠距工作日誌產生器 (防查核進階版)

本專案是一個純前端的單頁應用程式 (SPA)，專為遠距/機動工作者設計。主要功能為一鍵隨機生成具備「真實勞務感」、「隨機辦公地點」與「具體產出指標」的工作日誌，以應對潛在的稅務或勞檢稽核。

## ✨ 主要功能

1. **防查核隨機生成機制**：
   * **地點隨機化**：依照機率自動分配【遠距辦公】(70%)、【現場支援】(15%)、【線上會議】(15%)。
   * **動詞具體化**：內建「任務字典」，將空泛的任務自動轉換為具體的勞務行為（例如：「帳務分析」會隨機轉為「整理廠商請款單據並數位建檔」）。
   * **量化產出**：30% 機率自動附加具體成果標籤，如 `(完成進度約 80%)` 或 `(產出1份檔案)`。
2. **高度客製與手動微調**：生成後的表格可直接點擊進行文字修改，遇到國定假日或請假可一鍵刪除該列。
3. **雙重輸出模式**：
   * 支援直接列印 / 輸出為 PDF（自動隱藏操作按鈕與框線）。
   * 支援透過 Google Apps Script API 直接寄發 HTML 格式信件給主管。

## 🛠️ 如何修改與維護 (工程師指南)

如果你未來需要修改生成的邏輯或信件設定，請參考以下說明：

### 1. 修改工作項目與具體動詞字典
在 HTML 檔案中的 `<script>` 區塊，找到 `taskDictionary` 變數。你可以隨時增刪裡面的陣列，替換成你實際的工作內容：
```javascript
const taskDictionary = {
    "你的新任務名稱": [
        "具體動作1", "具體動作2", "具體動作3"
    ]
};

2. 修改隨機標籤的機率
地點機率：尋找 locationPool 變數，陣列中放入越多的該地點物件，出現機率就越高。

產出後綴機率：尋找 getRandomSuffix() 函數，修改 Math.random() < 0.3 中的數值 (0.3 代表 30%)。

📧 Email 寄信後端架構與修改教學 (重要！)
本程式沒有把老闆的信箱寫在前端程式碼中（為了資訊安全）。前端是透過 fetch 發送請求到 Google Apps Script (GAS) 部署的 Web App 網址。

修改收件人 (老闆信箱) 的步驟：
登入你當初建立 API 的 Google 帳號。

進入 Google Apps Script 儀表板。

找到負責接收此日誌的專案（對應前端的 scriptUrl）。

在 程式碼.gs 中，找到寄信的邏輯（通常是 MailApp.sendEmail 或 GmailApp.sendEmail）。

將裡面的收件人字串改為老闆的新信箱：

JavaScript
// GAS 後端範例代碼
function doPost(e) {
    var data = JSON.parse(e.postData.contents);
    // 驗證 token (通關密碼)
    if(data.token !== "通關密碼４碼生日") return; 

    // 👇 就是要在這裡改老闆的信箱 👇
    var toEmail = "boss_new_email@company.com"; 

    MailApp.sendEmail({
        to: toEmail,
        subject: data.subject,
        htmlBody: data.htmlBody
    });
    // ...回傳成功訊息...
}
⚠️ 最重要的一步：修改完程式碼後，必須點擊右上角的「部署」 > 「管理部署作業」 > 建立「新版本」並發布。只按儲存是不會生效的！
